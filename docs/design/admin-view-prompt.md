# The prompt

Paste into the Claude Design session. It has the repo, so this points rather than explains;
`docs/design/admin-view-brief.md` is the brief it refers to.

---

The operator's pane — the table that answers *is this still free?* and the four verbs
(invite, change email, revoke, delete). The brief is **`docs/design/admin-view-brief.md`**.

It is **already built and shipped, plain**, in 1.9.0. That was the phase plan: one viewer,
and the viewer deployed it. So every decision in §2 is a decision you are overruling
rather than a blank, and I would rather you argue with the ones that are wrong than
restate the ones that are fine.

🔴 **§3.1 is the ask.** It is a nine-column table on a phone, and this product has never
shown one. If the honest answer is a list in the devices-list shape with the numbers as a
machine-voice second line, say so and I will rebuild it. If it stays a table, §3.2 is the
next question: what scrolls, what folds, what goes.

Constraints that do not move: no page content on this screen, ever; amber is the only
colour and revoke is amber-and-dim like every other destructive control; no dialog —
revoke and delete confirm by a second tap on the same control; DM Mono for every value,
because the server counted them all.

Words are §3.3 — none of mine are from the brand and all of them are yours to replace.
