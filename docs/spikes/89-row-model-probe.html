Row Model Probe

Does contenteditable give knag native cross-row selection without destroying byte preservation? This page answers that, on the device that decides it. Nothing here touches the real app.

Run it on the iPhone

  1. Long-press inside a line, then drag the handles down across several lines. If the selection stops at one line, the whole approach is dead and nothing below matters.
  2. Copy the selection. Watch the Selection panel — it shows exactly what would land on the clipboard.
  3. Select across a checkbox line and copy. Does it read - [ ] milk, or does the checkbox vanish?
  4. Type. Press Enter mid-line. Press Backspace at the start of a line. Watch Structure — it goes red the moment the browser invents an element the model does not have.
  5. Edit the indented line and the one with trailing spaces. Watch Bytes.

The document

One contenteditable container, one child per line. Checkbox prefixes are contenteditable="false" islands. Deliberately loaded with the awkward cases: a blank line, leading indent, trailing spaces, and a * bullet that must stay a *.
